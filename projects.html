A modern, responsive website for Meiyal Foundation, which empowers women and children in plantation communities across Sri Lanka. The site presents the foundation’s work and makes it easy for visitors to get involved.

  • Clean, community-focused design
  • Mobile-first responsive layout
  • Pages for Home, About, Programs, Membership and Leadership
  • Fast loading with smooth, restrained animation

Education platform

Tuition Management Platform

A full tuition management platform for teachers, students and administrators. Teachers run their classes online, students track their work, and administrators manage users, classes and payments in one place.

For teachers

  • Create classes with announcements and assignments
  • Grade submissions and upload notes, past papers and video lessons
  • Track student payments and view an analytics dashboard

For students

  • Enrol in classes, submit assignments and download study materials
  • See upcoming deadlines at a glance on a personal dashboard
  • View payment history

For administrators

  • Manage all users and classes from an admin panel
  • Generate payment reports
  • React
  • Context API
  • React Router
  • Tailwind CSS
  • Axios
  • Node.js
  • Express (MVC)
  • PostgreSQL
  • JWT
  • Multer

Security: Helmet, CORS, rate limiting and bcrypt password hashing.
